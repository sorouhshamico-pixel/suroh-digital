# نشر صروح الرقمية على Hostinger

## 1. الدومين الفرعي
أنشئ الدومين الفرعي:

`digital.suroohalshami.com`

واجعل Document Root يشير إلى مجلد `public` داخل المشروع إن كان ذلك متاحًا في لوحة الاستضافة.

## 2. GitHub
أنشئ مستودعًا خاصًا باسم مناسب مثل:

`sorouh-digital`

ثم ارفع المشروع إلى فرع `main`. يفضّل استخدام فرع `development` للتطوير ودمجه إلى `main` بعد نجاح فحص GitHub Actions.

## 3. Git Deployments في Hostinger
اربط المستودع بميزة Git Deployments في Hostinger، واختر فرع `main`، ثم فعّل Auto Deploy إذا كان متاحًا في خطتك. لا تضع كلمات المرور أو ملف `.env` داخل GitHub.

## 4. قاعدة البيانات
أنشئ قاعدة MySQL ومستخدمًا مخصصًا، ثم استورد الملف:

`database/schema.sql`

بعد ذلك انسخ `.env.example` إلى `.env` على السيرفر وأدخل بيانات قاعدة البيانات.

## 5. إنشاء أول مدير
من SSH داخل مجلد المشروع:

```bash
php database/create_admin.php admin@example.com 'StrongPasswordHere' 'مدير صروح الرقمية'
```

استخدم كلمة مرور قوية مختلفة عن أي حساب آخر.

## 6. الصلاحيات
تأكد أن PHP يستطيع الكتابة داخل:

`storage/logs`

وأن بقية ملفات المشروع غير قابلة للكتابة للعامة دون حاجة.

## 7. التحليلات
بعد إنشاء الحسابات، ضع معرفات GTM وGA4 داخل `.env`.

## 8. الاختبار قبل الإطلاق
اختبر:

- الصفحة الرئيسية
- كل صفحات الخدمات
- `/blog`
- `/admin/login`
- إرسال نموذج تجريبي
- الضغط على واتساب والاتصال
- ظهور الأحداث في لوحة التحليلات
- الروابط التي تحتوي UTM
- `robots.txt`
- `sitemap.xml`

## 9. النسخ الاحتياطي
GitHub يحتفظ بالكود فقط. فعّل أيضًا نسخ Hostinger الاحتياطية لقاعدة البيانات والملفات المرفوعة.
